What is CloudBridge?

CloudBridge turns your Android phone or tablet into a full cloud file manager. It uses rclone to talk to your cloud storage, so it supports every provider rclone supports — from Google Drive, OneDrive and Dropbox to decentralized storage like Internxt. You can browse, upload, download, move, rename and delete files, stream media, and schedule automatic sync tasks.

CloudBridge is free and open source software (GPLv3). It is a fork of RCX, which is itself a fork of rcloneExplorer.

Highlights

  • File management — list, view, download, upload, move, rename, delete.
  • Streaming — stream media, serve files and folders over FTP, HTTP, WebDAV or DLNA.
  • Sync tasks — schedule recurring syncs between any remotes and local storage.
  • Encryption — keep files private on any provider with 256-bit crypt remotes.
  • Local storage — Storage Access Framework (SAF) support for SD cards and USB devices.
  • Always current — regularly updated to the newest rclone version.
  • Material 3 design — including dark theme.
  • All architectures — ARM, ARM64, x86 and x64, Android 7+.
