# CloudBridge 1.0.2 — Reliability and security fixes

## What changed

- Improved saved sync and copy tasks, including cloud-to-cloud transfers and accurate failure reporting.
- Fixed bulk deletion stalls and misleading notifications; added **Cancel all transfers and syncs**.
- Improved Internxt sign-in recovery and reduced false or stale session-expired alerts.
- Fixed shared-upload staging and duplicate-filename handling.
- Improved Android file access and WebDAV compatibility, with stronger credential and file-sharing protections.
- Updated rclone to 1.75.2, retaining CloudBridge's Internxt login improvements.

## Downloads

- Most modern Android phones should use the **arm64-v8a** APK.
- If you are unsure which ABI your device needs, install the **universal** APK.
- Download `SHA256SUMS` alongside your artifact to verify its SHA-256 checksum.
