# CloudBridge 1.0.3 — Task fixes and distribution preparation

## What changed

- Improved task reports, follow-up tasks and transfer failure handling.
- Fixed configuration import and backup behavior, and improved file-list and remote-configuration interactions.
- Kept secondary screens clear of Android system bars.
- Refreshed the README, store artwork and screenshots, including German store metadata.
- Added Obtainium setup links for signed stable universal APKs.
- Prepared developer-signed F-Droid packaging with unsigned verification builds, an offline rclone build mode and a publishing guide. Official F-Droid inclusion is still pending review and independent build verification.

## Downloads

- Most modern phones should use the **arm64-v8a** APK; use **universal** for Obtainium or when unsure.
- The **AAB** is for Google Play Console and is not directly installable.
- All release APKs use the existing CloudBridge signing certificate. This release's universal APK and AAB use version code **32610**; ABI APKs add 6–9.
- Download all artifacts and `SHA256SUMS` to verify their SHA-256 checksums.
